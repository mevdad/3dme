# 3D Me — Code Smasher

Мини-сцена на three.js: на персонажа (Mixamo-риг) летят шары JS / PHP / Python / CSS / Web3 / AI,
он разбивает их приёмами.

Запуск (сборка не нужна): `python3 -m http.server` и открыть http://localhost:8000

## Добавить анимации
- Положить `.fbx` в `assets/anims/` и перечислить в `assets/anims/manifest.json`:
  `[{ "file": "idle.fbx", "role": "idle" }, { "file": "punch.fbx", "name": "Punch" }]`
- или перетащить `.fbx` в окно браузера (имя с `idle` = стойка в покое, остальное — приёмы).

Момент и точка удара у каждого приёма определяются автоматически: берётся конечность, которая
быстро движется и дальше всего выносится вперёд. Шар рассчитан так, чтобы долететь туда в этот момент.
