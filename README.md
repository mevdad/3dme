# 3D Me — Code Smasher

Мини-сцена на three.js: на персонажа (Mixamo-риг) летят шары JS / PHP / Python / CSS / Web3 / AI,
он разбивает их приёмами.

Запуск (сборка не нужна): `python3 -m http.server` и открыть http://localhost:8000

## Ассеты
`assets/models/martelo.glb` (1,3 МБ) — модель и все 4 анимации в одном файле: текстуры WebP 1024², сетка
сварена и квантована (KHR_mesh_quantization), клипы пересэмплированы. Исходные FBX были ~22 МБ
(остались в истории git).

## Добавить анимации
Перетащить `.fbx` (Mixamo, тот же скелет) в окно браузера — клип добавится в конец раунда как новый приём.
Чтобы добавить насовсем, нужно пересобрать `martelo.glb` с новым клипом.

Удары внутри приёма находятся автоматически: быстрые «выбросы» руки / ноги / головы от тела.
В одном приёме их может быть несколько (в Fist Fight — 5) — на каждый удар летит свой шар,
рассчитанный так, чтобы долететь в нужную точку ровно в нужный кадр.

Раунд: Fist Fight (серия ударов) → Jab & Kick → Headbutt → Chapa Giratoria → пауза в стойке → снова.
Боевая стойка — первый кадр Fist Fight: с неё начинается серия и в неё же персонаж возвращается в конце.
Приёмы стыкуются без пауз: следующий кроссфейдится (smootherstep, 0,45 с) в хвосте предыдущего.
Выпады вперёд сохранены (иначе, например, удар головой не читается), но после каждого приёма персонаж возвращается в ту же точку; стартовый разворот каждого клипа
подогнан под стойку, поэтому на стыках тело не проворачивается.
Порядок задаётся массивом `ORDER` в `src/main.js`.
